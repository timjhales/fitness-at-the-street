# Fitness At The Street — Website Project
*Summary of conversation · Tim & Claude · April 2026*

## Background
Fitness At The Street is a strength-focused, community-driven gym in Brundall run by Kim and Steve. They have an existing online presence — a Google Business Profile linking to a Trainerize site for bookings, an active Facebook page, and Instagram. They have wanted a website for some time but have been concerned about losing control of it and complexity.

Tim is proposing to build the site as a community gift, with no financial transaction, adding it to his portfolio. The ethos is full ownership and independence for Steve from day one.

## Domain
`fitnesstatthestreet.co.uk` is available at low cost. The immediate action is to purchase it and redirect it to the existing Trainerize site as a quick win — a more professional-looking URL that's easy for members to remember.

## Technical approach
- Create a new Google account tied to the gym's domain — Steve owns all credentials from the outset
- Host the site on Cloudflare Pages — same platform Tim already uses
- Store website source files in Google Drive under the new account for central, accessible storage
- Deploy to Cloudflare Pages manually — no Git or GitHub required for this project
- Embed the gym's public Facebook feed directly into the site — no login required, updates automatically, no duplication of effort for Steve

> **Note on Facebook embedding:** Public Facebook pages can be embedded on any website using Facebook's embed code. No credentials needed. The feed updates in real time. Test this using the gym's existing Facebook page before the conversation with Steve.

## Design thinking approach
The project will follow a design thinking structure. The priority is discovery first — not arriving with a predetermined solution.

1. **Discovery coffee chat** — listen to Steve's actual needs, concerns about control, and vision. Do not present solutions at this stage.
2. **Define scope** — based on what you hear, agree on what the site needs to do. Keep it lean.
3. **Build collaboratively** — involve Steve so there are no surprises at handover.
4. **Handover with documentation** — plain English instructions, screenshots, a short walkthrough. Steve should feel confident managing it independently.

## Content strategy
Steve and Kim are busy running a gym. The site should not create a new content burden. The approach is to use Facebook as the content engine and the website as a syndication hub — embedding the live feed so the site feels current without any extra work. Over time, popular Facebook posts could be lightly expanded into website articles, but this is optional.

## Key principles
- Steve owns everything — domain, Google account, Cloudflare, all credentials
- No dependency on Tim after handover
- Present in outcomes, not technical language — "a control panel you log into" not "Cloudflare dashboard"
- Documentation written in plain English with screenshots
- Trainerize remains the operational engine for bookings
