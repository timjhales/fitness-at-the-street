AW26 Class Graphics — Format Options

The latest class artwork has a strong, distinct look. Since it's designed as a portrait poster and the site's current tiles are square, here's a look at how each option plays out — so we can pick the best path together.

Why the site leans on real photos
Most of the site so far — instructor bios, the reviews section, the class tiles — leans on real photography rather than stock imagery or illustration. That's been a deliberate choice, not just a default: for a local gym, the biggest question a prospective member has is usually "is this a place I'd feel comfortable walking into?" — and real photography of real training environments and movement tends to answer that more convincingly than illustrated artwork, simply by looking grounded and specific rather than generic.
That's the lens worth keeping in mind for the new graphics — not because illustration can't work, but because it's a different way of communicating, and it's worth being intentional about whether this campaign sits alongside the real-photo approach or represents a shift in it.
One specific thing worth flagging: because the illustrated figures use the same character style across every poster, the tiles end up looking quite uniform side by side — whereas the real photos naturally vary from one to the next, which gives the tile grid more of a varied, lived-in feel rather than a single repeated template.
The core question: square tiles or portrait posters?
The site's class tiles are currently a fixed square. The latest graphics are 1080×1350 (portrait), with the logo at the top and the class name at the bottom. Here's the same graphic shown in the site's current square format, force-cropped to square, and at its own native shape.

Two smaller things worth a quick decision

Logo styling — the new graphics use a chrome/metallic text effect for "Fitness @ The Street," a different treatment from the brand's teal logo. Worth deciding whether that's an intentional stylistic flourish for this campaign, or whether it'd be worth swapping in the brand teal for consistency.

Decades — this one's a real photo with the existing "Decades Reloaded®" sticker, rather than the neon illustration style used across the other nine. Might be worth a matching neon version if we want the full set to feel like one campaign.

Recommendation: the new graphics look best kept at their native portrait shape rather than cropped into today's square tiles — see the "Updated Format" tab for what that looks like across the whole page. That would mean a small layout change to the Classes page tiles.

Happy to go whichever direction feels right — this is just to make the trade-off visible rather than describe it.
